# ADR-001 - C++ for the engine

C++ was chosen for the engine due to its high performance in environments and systems where speed, efficiency and robustness is crucial.

Other languages and tools provide similar, if not easier ways of building the same architecture, but they all come with overhead, frameworks, different build tools and utils, as well as slower executions (compared to regular C++ performance)

For the reasons above - C++ was chosen as the final engine language and architecture.
